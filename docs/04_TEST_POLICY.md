# 最小测试政策

维护长期不变量，默认不新增测试文件。零新增测试是正常交付；也不能以此证明正确，或删除真实回归、放宽断言换绿。

## 保留什么

| 不变量 | 优先承载 |
| --- | --- |
| common/platform、domain/application、客户端/服务端、通用/builtin依赖边界 | 既有 PackageArchitectureTest 等轻量架构检查 |
| 唯一成员/敌对/资源/终态、唯一环境参与者、稳定轮转与合并不赠预算 | 既有 EncounterAuthority、EnvironmentParticipant 等纯规则测试 |
| 同ID同负载幂等、异负载拒绝、接受边界收费、取消保留效果、UNKNOWN不重放 | 操作/资源/结果测试及必要原生接缝 |
| 真实等待不推进、未执行不扣步、delay/顺序/唯一队列owner迁移 | RoundTime与既有环境检查 |
| 实例/世代失效、来源与随机保持、释放幂等、不可变历史与引用保留 | ActorHistory、Effect/Process及恢复检查 |
| 查询只读、有界输入/计算、非有限值拒绝、选择/投影迟到失效 | 既有规则/协议/输入检查 |

测试名称、行数和历史批次不是价值依据。TacticalPlan 的 NaN/Infinity/范围拒绝等小测试可保护真实合同；大型重复验收脚手架也可以归并。

## 修改与新增

先定位独有断言及对应有效规则。只删除重复、过时或已无有效合同的内容；归并前确认独有不变量仍被保护，不把全部测试塞成一个巨型文件。旧固定field预期可按已确认玩家中心规则更新，但资源/授权/去重不能随之放宽。

新增前说明：保护什么跨阶段不变量、既有断言为什么不够、为何需在这一层证明。优先扩展已有参数/断言；“新增类”“覆盖率低”“本阶段验收”都不是独立理由。不规定硬性数量，不新建阶段测试框架、日期验收报告、兼容用大工程或常驻探针。

源码扫描约束真实依赖边界，不锁死注释、私有类名、调用顺序或迁移文件清单。测试代码不进入 docs/legacy；删除后的历史由Git追溯。

## 平台与客户端

GameTest只保护纯值层不能证明的原生事件门控、队列接管/释放、物品守恒、实例观察/恢复等接缝，优先复用代表性夹具。必须清理会话、监听、缓存、世界和静态状态；失败先区分生产bug、夹具泄漏、旧预期或环境，单项通过不等于整套隔离良好。

UI长期检查保护布局/命中一致、输入消费及选择/响应身份，不维护像素截图或固定组件数量。无窗口检查不能替代真实键鼠、镜头遮挡或双客户端。重启launcher与测试注册留在测试源码，不能进入发布jar；chunk/SavedData夹具恢复不能冒充普通专服完整level.dat续战。

## 按改动选择检查

| 改动 | 常规检查 |
| --- | --- |
| 文档 | 本地链接/锚点、规则一致性、归档内容保全；不启动游戏 |
| 构建/调试依赖 | 配置及实际依赖解析、默认构建、发布依赖/产物隔离；不为配置改动新增长期测试 |
| common规则 | 相关既有JUnit，必要时完整common；保持Java17 |
| 26.1接入 | JDK25编译/构建与受影响的少数既有平台检查 |
| 输入/视觉 | 最短真实键鼠链；联机变化补相关双客户端路径 |
| 过程/持久化/队列 | 相关不变量与代表性真实保存/停止/第二进程恢复 |
| common跨target签名 | 集成节点必要target构建，本地串行，避免同时写common/build |

当前26.1 `check`依赖gameTest编译、`verifyUiProjection`、`verifyDebugDiagnostics`、`verifyControlPolicies`；`build`不自动执行GameTest。默认check只承担便宜稳定的不变量，其余按影响选择。CI的push/pull_request已包含`targets/**`，不再写成待补路径；配置存在不代表远端通过。

AutoJS通过显式`-Pautojs=true`和`localRuntimeOnly`进入本地运行，不进入编译或发布API/runtime依赖；默认构建保持关闭。配置验证与依赖下载不是AutoJS脚本实机验证。

## 证据与停止条件

每次只在当前状态记录基线（含未提交工作区）、实际命令/场景、结果和未覆盖范围。没有匹配测试、跳过、旧通过记录都不能计作本次成功。重试说明失败原因及修正，不隐藏首轮失败。检查通过后无新风险不反复扩大全套运行。

简短手工记录按改动选用：field跟随后行动、成员介入/退出、攻击后继续移动、免费方块交互、环境等待对照、已知阶段跨进程恢复。性能只用临时采样记录工作量、分配和热点，不把某台机器毫秒数写成脆弱CI阈值。
