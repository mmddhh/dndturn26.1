## 1. 状态与证据约定

| 状态 | 含义 |
| --- | --- |
| 缺陷 | 已有实现违反其状态不变量或已声明路径，需修复 |
| 已决定／未实现 | 产品方向已有明确答案，缺执行或集成 |
| 部分实现／待验收 | 有代码，仍缺覆盖或运行证据 |
| 未决边界 | 输入资料不能唯一确定行为，不给默认答案 |
| 冲突 | 资料或代码与目标不一致，仅列双方与影响，不自动裁决 |
| 搁置 | 已决定暂不做；不得以旧枚举、原版默认或实现便利补全 |

源码事实优先用于描述“现在做了什么”；已有明确设计与源码不一致时登记冲突，不把源码缺陷变成目标规则。正常行为修复建议不等于新增产品决定。

本快照仍不能通过 M4/M5/M6 完成门槛；正常战术入口保持接通，缺口不通过开发开关规避。

## 2. 优先剩余验收

### G02 — 箭矢调度生命周期

仍需真实卸载/重载、死亡/离线来源、自然移除与跨重启调度重建的证据。历史来源与实时绑定独立，不能因撤销绑定丢失因果历史。

### G03 — 跨会话箭矢剩余场景

仍需来源死亡/离线、目标移动/离场、三会话关系、重复碰撞及合并异常恢复验收。不能用旧碰撞位置追击已移动目标，合并不等待所有箭销毁。

### G04 — 全攻击伤害证据

仍需 service 授权链下事件取消、装备耐久、击退、准备/执行异常、重试与真实重启的完整 trace 验收。UNKNOWN 中已观察净损失不代表全部副作用已知；普通箭覆盖不能推广到尚未接入的药水、爆炸等攻击。

### G27 — 多人退出的真实联机验收

仍需两个真实客户端验证：被 Mob 锁定时场内 EXIT 拒绝保持界面与资源；无锁定时场内 EXIT 完成控制、订阅与 UI 交接；最后玩家即使越界，仍被锁定时不得结束会话；留场者继续产生结果时，不向离场连接发送后续战报。GameTest 的成员/版本/重试及测试位置布置不等于真实网络移动证明。

规则已明确，见玩家规则第 11 节；本项不再等待产品决策。
