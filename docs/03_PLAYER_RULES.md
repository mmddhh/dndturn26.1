# DNDTurn：玩家可观察的顶层游戏规则

整理日期：2026-09-26；实现参照为 `DNDTurn-sources(20260926-073919).zip`。规则依据为 `docs(2).zip` 与本会话已经明确的用户修订。本轮只更正文档中的重复、冲突与实现状态，不新增玩法决定。历史 R/D/Q 编号保留。

**读法：本文规范玩家应观察到的行为，不证明这些行为已全部实现。**源码事实由01维护，活动缺口由02维护；04中的目标架构不得反向修改本文费用、AI政策、退出条件或时间规则。

实现交接见 [01_IMPLEMENTED_DECISIONS.md](01_IMPLEMENTED_DECISIONS.md)，缺口及冲突见 [02_GAPS_AND_CONFLICTS.md](02_GAPS_AND_CONFLICTS.md)。本文件不重复程序包结构、Mixin、存档字段或权限实现细节。

## 1. 先区分当前体验与目标玩法

- **当前受限实现**：已有源码落点，但尚未完成完整客户端与联机验收。本文沿用的“原型”表示成熟度，不代表独立的会话类型或开发开关。
- **目标规则**：设计已明确，当前可能只有部分实现或尚未接通；不应向玩家承诺已经可用。
- **冲突**：设计与实际行为尚未一致，或资料不能唯一确定；列出差异，不替用户选择。
- **搁置**：当前不做，不暗示默认采用原版或永久取消。

正常 `/dndturn tactical` 与网络意图入口已接通，当前支持 Player/Zombie 流程及多人同意。身份、同意、阶段、资源及损坏存档保护继续生效，不使用实验开关隐藏缺陷。入口可用不代表完整玩法或崩溃后续战已经验收。

能力支持范围与运行验收统一见 `02_GAPS_AND_CONFLICTS.md`；不能从通用行动名称推断所有原版或模组物品已支持。

## 2. 开始战斗与候选状态

**目标规则（R11–R18；当前受支持的玩家/Zombie 流程已有部分实现）：**

1. 由玩家主动发起回合制。怪物仅仅发现玩家或取得攻击目标，不会在普通世界中自动创建战斗场地。
2. 建立候选会话并排列先攻；每个候选回合结束时检查当前敌对关系，有明确敌对则正式开战。
3. 已经处于回合制影响范围内时，合法攻击行为本身即可触发正式开战。未命中、零伤害或伤害被取消，不把这次合法攻击改成“没有攻击”；未通过授权的非法请求不触发开战。
4. 正式开战时重新掷先攻。触发开战的攻击消耗一次动作，重掷不会返还该动作。
5. 敌对关系可以是多方且有方向，不简单等同“玩家对所有怪物”。当前通用敌对/感知适配尚未完成，不能将非敌对 Mob 的合法地面移动误解成已授权攻击。
6. 不同玩家互相视为中立，当前禁止 PvP；同场、同意入场或其他玩家正在战斗不建立玩家间敌对关系。

**2026-09-25 用户明确修订：**附近没有敌人也可以进入回合制；允许只有玩家和环境回合。没有敌对关系时保持候选状态，玩家结束回合后推进环境阶段，再返回玩家回合并刷新资源，不因没有敌人自动结束。多人同意、场地采样、成员授权与主动 EXIT 边界规则继续适用。

**首次攻击优势（R17，规则 0.8）：**每场战斗、每名攻击者有一次首攻资格，候选阶段与正式阶段共用。首次合法攻击登记前，若受击生物当时没有把攻击者作为目标，该次命中检定获得优势。未命中、取消或重掷先攻均不返还资格；非法请求不消耗。当前不同生物的识别适配尚不完整。

## 3. 多人同意

**目标规则，已接原型，真实多客户端仍待验收（R20–R22，规则 0.6/0.9）：**

- START 表达发起者同意，其他名单成员在模态窗口确认；当前正常入口不依赖旧 `multiplayerConsentEnabled` 或 `prototypeEnabled` 开关。
- 开启后，发起者先提出请求。等待同意期间世界继续运行，不先暂停所有人。
- 请求中的玩家名单随范围变化。仍在名单中的玩家保留已给出的同意；离开后移除同意，再进入须重新同意。
- 当前名单全员同意后才固定建场。请求从发起起 20 秒失效，不因名单变化无限续期。
- 重叠请求自动合并，沿用最早发起时刻的截止时间，并保留仍有效的同意。
- 拒绝或超时使请求失效，原世界活动继续，不补放或重演等待期间的交互。

**已决修订 C01：**名单内玩家掉线取消整个同意请求；普通走出范围只移除个人同意。

## 4. 战斗场地与边界

**已确定且已有几何实现（R12、R19、R27–R28；运行边界仍待验收）：**

- 战术参与判断和模拟暂停使用同一连续场地，不采用“圆形选人、整区块暂停”。
- 建场时发现范围内所有实体的中心位置都可以作为场地锚点；这不意味着所有实体都会获得先攻和动作。
- 每个锚点绘制相同半径的竖直圆柱；连接锚点之间的区域并填满内部。一个锚点形成圆柱，两个同高锚点形成胶囊形水平轮廓，多个锚点形成没有内部空洞的圆角凸区域。
- 场地顶部为最高锚点 Y＋16，底部为最低锚点 Y−16；顶底保持水平，不跟随地形倾斜。
- 锚点建立后固定。单位移动、死亡、离开或外部射手加入，不自动拖动或扩大场地；会话合并时才按建场规则重新采样。
- 实体是否跨界按自身中心判断；方块按方块中心判断。不是用实体所在方块代替实体边界，也不要求整个包围盒越界。
- 普通跨出边界不自动退会，但不能在场地外发起受会话授权的主动移动或攻击，已有行动会结算并释放。明确退出及死亡、掉线、换维度、卸载另行处理。

**当前开发预设：**水平发现范围参数 16、竖直发现参数 8、笔刷半径 8；发现区最多采样 16 区块、64 个锚点，超出或未加载可拒绝建立。发现范围只是寻找锚点的范围，不等于最终场地。

**已决修订 C03：**发现竖直默认 ±8，最终场地按最高/最低锚点 ±16，两层保持独立。

## 5. 回合、资源与合并

**已确定规则，核心轮转及受限流程已有实现（R05、R08、R15、R23–R25）：**

- 先攻以 d20 决定，先攻高者先行动；同值使用随机的次序依据，并保持可稳定排序。
- 自己的回合开始时取得一份基础移动预算、一个动作和一个反应。动作与移动用于本回合；反应供相应触发使用，到下次自身回合重新获得。开战触发动作、合并迁入资格等明确例外不会被刷新抹掉。
- 当前基础移动开发预设为 **28 tick**，环境阶段预设为 **20 个实际获准推进的 tick**；均按会话捕获；旧会话沿用保存值，新会话读取当前配置，合并后的后续回合使用主会话预算。
- 可以分段移动，停下执行合法行为后继续使用剩余移动额度。
- 成员回合后有固定环境阶段。它只推进已归类的环境对象，不给所有实体一个自由行动窗口。
- 后来加入的单位即时进入名单，下一轮才取得行动资格。
- **2026-09-26 用户修订：**发现范围内非敌对 Mob 也纳入先攻与回合移动，候选阶段不跳过其移动。当前通用地面导航适配复用既有原版路径，或以原版随机漫步算法提出路径；仅自身移动租约期间推进原版导航、控制、travel 和碰撞，并按实际位移 tick 扣预算。没有路径可以原地结束，不因此产生敌意。该移动能力不授予攻击、繁殖、工作或任意 Brain/Goal 副作用；特殊移动适配边界见 G21。

**会话合并（正常战术会话已接统一路径，完整联机与异常恢复仍待验收）：**

- 重叠会话取当前回合单位先攻最高者所在会话作为主会话。例如 11、12、13 取 **13**，不是 11。
- 正式合并在指定的下一环境回合入口发生，不能在已经执行了一部分的环境回合中随意插入。
- 保留各成员原有先攻、已消费资源、反应和资格，不全员重掷或白送新预算；迁入者下一轮才能行动。
- 按首次建场规则重新采样生成场地；新场地若碰到更多会话，还需纳入合并检查。
- 存活箭矢保留来源，不要求全部落地或消失后才合并。
- 成员名单管理与世界推进分开；不把成员加入强行拖延到投射物消失。

同先攻与环境阶段无当前单位时采用稳定的次序依据处理。跨会话箭矢、异常恢复和真实合并显示仍有缺口，见 G03/G15。

## 6. 移动费用

**已确定，普通移动已有实现，混合位移与真实客户端仍待验收（R36–R42）：**

| 实际情况 | 移动费用 |
| --- | --- |
| 获准的普通主动移动，且该服务端 tick 确实产生位移 | 1 |
| 获准的水中主动移动，且确实产生位移 | 2 |
| 合法起跳 | 在该 tick 普通费用之外附加 1 |
| 空中只有被动下落、无主动水平输入 | 不因下落收移动费 |
| 空中存在主动水平输入并产生相应主动位移 | 按主动移动 tick 计费 |
| 撞墙、受阻或零实际位移 | 0 |
| 同一服务端 tick 收到多个移动包 | 只结算一次，不逐包收费 |
| 合法被动击退、位置纠正 | 0 |
| 同 tick 混合主动输入与外力/特殊位移，无法证明主动贡献 | 0，并保留混合归因结果 |

距离、格数与速度只用于路径、显示和校准，不决定扣费。旧“走六格”“水中每格双倍”不再是运行时费用公式。

首版普通移动许可只覆盖步行、跳跃和水中移动。骑乘、鞘翅、旋转冲刺及飞行不能借此获得许可；行动期间切入这些模式要结算并释放已有普通移动控制。

路径是会被环境改变而失效的提案。障碍变化可能中断或拒绝移动；正常行走接受原版碰撞，不用瞬移完成。复杂体型与路径完整显示仍未完成。

## 7. 攻击、命中与伤害

**已确定且基础计算已有实现（R01–R04、R43–R48）：**

1. 命中检定为 d20＋5，与目标 AC 比较，大于或等于 AC 命中。
2. 自然 1 必定未命中；自然 20 必定命中且暴击。
3. 优势掷两次取高，劣势取低；同类不叠加，优势与劣势同时存在时抵消。
4. AC 为非负的护甲值向下取整，加上持盾的 2 点。持盾 AC 与实际举盾耐久判断是两件事。
5. 当前基础伤害扣除非负的韧性向下取整值，最低为 0；暴击将这个结果翻倍，然后对最终伤害向下取整。武器输入保留有限小数，不能先把武器伤害截成整数。
6. 合法攻击**实际开始执行**即消耗动作，无论命中与否；仅发送网络请求、选择武器、预览、查询或接近不等于攻击开始。非法请求不应先扣费或改变目标。

可写为：

`AC = max(0, floor(armor)) + (持盾 ? 2 : 0)`

`伤害 = floor(max(0, 基础伤害 - max(0, floor(toughness))) × (暴击 ? 2 : 1))`

玩家近战基础伤害读取主手武器提供的攻击伤害属性；当前 Zombie 适配读取该生物攻击伤害属性。生命值仍使用原版实体生命值，死亡/复活结果遵从合法原版生命周期。

**原版效果衔接（目标规则，现有受限伤害路径已接，完整覆盖待验收）：**

- 同一次战术伤害不能再被原版护甲、盾牌、附魔、抗性重复减伤。
- 保留原版吸收生命与合法装备耐久。实际举盾且该次战术攻击被接受时才桥接盾牌耐久，还需遵守原版方向等判断；取消、免疫、零伤害和请求重试不能重复损耗。
- 合法攻击/受伤入口消除旧受伤无敌帧，并阻止这次战术伤害产生新的受伤无敌帧。非法操作不能清掉目标状态。
- 战术击退由配置控制，默认关闭。启用后，暂停目标受到合法击退立即按原版碰撞移动，不等待自己的回合；这不授予额外自主行动。
- 未命中、免疫、取消、零伤害、吸收及实际生命损失应被区分；未知结果不能自动当作“完全没发生”。

**搁置 H02：**按伤害类型的抗性减半和免疫归零尚无完整类型数据与叠加规则。不能把上述“不重复原版减伤”理解为所有免疫规则都已完成。

**借机攻击（R57，目标规则、未接通）：**主动移动离开另一单位攻击范围前先暂停该步；反应者可从物品栏选择武器、确认并消耗反应进行一次近战。多个反应者共用最多 100 个实际服务器 tick 的确认窗口，收集选择后按稳定先攻顺序逐次复验、结算；掉线或回合结束视为放弃，仍可移动时恢复移动。被动位移不自动等同这种主动离开。

## 9. 暂停与环境回合

**目标规则（R28–R35、R49、R67–R71；当前只覆盖列明通道）：**

- 区域暂停的是模拟推进，不把场地变成与外界隔绝的防护罩。区域外继续运行，外部改变可以进入，但须遵守相应分类与授权。
- 环境阶段只推进明确归为环境的对象：已接通的方块/流体计划更新、随机方块更新、方块实体、block event，以及明确登记的投射物等。
- 不因对象“不是参战者”“没有目标字段”或“来源未知”就自动让它运行；参战者也不在环境回合全体自由运动。
- 环境预算按实际获准推进计数。未加载、全局冻结等没有实际推进时不扣预算。
- 全局冻结使用原版全局模式；局部会话仍保留，但不借此继续移动、环境步骤或新的跨域效果。
- 计划更新的剩余延迟和相对先后应保留；恢复不应补发成重复更新。正常释放已有处理，磁盘重载及崩溃仍待验证。

**首版边界：**不承诺完整控制天气、世界生成、即时红石/活塞及其他未分类邻居更新。首版环境实体白名单不包含投掷器产生的掉落物和火焰。发射器的箭与投掷器的物品不能混为同一类。自然环境伤害的最终战术规则仍搁置。

**流体目标规则：**外界流体第一次跨界写入属于允许的外部变化；区域内后续计划更新与传播只在环境步骤推进。完整边界仍待验收，不能声称当前已把所有外部更新可靠门控。

## 10. 外来箭矢与来源

**已确定目标，普通箭有部分实现，剩余覆盖见 G02–G04：**

1. 箭矢首次进入区域就应接受区域调度，不能自由穿越后才在受伤事件里补登记。
2. 仅穿过场地、没有明确攻击证据，不让射手自动参战。可信目标锁定或原版扫掠碰撞明确指向成员时，才构成对成员的攻击。
3. 在不可逆命中副作用前，把可识别且在线/存活的射手并入目标会话。之后 d20 未命中、零伤害等不撤销介入。射手在场地外也保留成员与来源，但不能直接在外开启主动行动。
4. 射手已经属于另一会话时应进入合并流程；不能让箭绕过目标会话直接结算，也不应因检查次序提前丢掉合法合并机会。
5. 死亡/离线射手不被恢复为可行动成员；已记录的历史来源仍保留。
6. 真正没有可识别射手的箭，没有射手动作资源或首攻优势；按 d20＋5 对 AC 做战术命中，不按速度追加伤害。缺少本次必需证据的箭应明确拒绝，不能把来源不明当作充分许可。
7. 已登记投射物由环境阶段调度，不等原主人回合；原主人死亡、离线或结束行动不抹去归属。
8. 不增加模组主动投射物超时。原版碰撞、自然移除与各自寿命保留；暂停不消耗被暂停的模拟寿命，现实存续可无限延长。没有统一的“600 tick 到期”规则。

**当前实现限制与冲突：**

- 普通箭以捕获的固有基础伤害结算。带附魔武器、特殊弹药、着火、穿透及未支持碰撞会被拒绝；目标设计的附魔增伤/药水组件尚未实现（C02）。
- 现有检测仍可能在区域外提前暂停；目标已明确为精确边界接管，区域前障碍先发生，此项待实现（C04）。
- 旧会话结束后再入域、AB 双向合并有回归；完整生命周期、PvP 和异常恢复仍待验收（G02/G03）。
- 已知且未隔离的箭在来源会话结束、无活动调度域时恢复原版推进；保留历史来源，再入域重新接管，不增加主动超时（C06）。UNKNOWN 隔离例外见第 11 节。

## 11. 退出、保存与异常结果

**目标规则（R61–R66），正式恢复尚未完成：**

- 死亡、掉线、换维度或实体卸载会移除该成员并释放其控制；最后成员离开时结束会话。箭矢保留历史来源，不必等待它们消失。
- 正常退出不应残留暂停、移动控制、选择或战术镜头。

**2026-09-26 用户修订：**没有其他存活 Mob 以请求者为当前 target 时，允许在场内直接 EXIT；仍被锁定时须先让实体中心越界。个人退出只释放本人控制、订阅及界面，不结束其他玩家的会话。场内合法退出者不再被原会话的区域门控冻结；重新加入会话后重新接受控制。只要会话中仍有玩家被 Mob 作为 target，就不允许主动结束整个回合制会话，包括最后一名玩家已越界的情况。服务端按当前已加载 Mob 的有效 target 判断，不按物种标签、历史敌对记录或 ACTIVE 阶段推定。拒绝保留成员、界面与资源，不传送玩家。死亡、掉线、换维度及卸载的生命周期清理独立执行。多人真实输入与显示验收见 G27。

本人合法回合允许免费切换热栏、整理自身背包及装备。这不授权丢弃、外部容器、合成、使用物品或特殊移动；这些操作仍需各自规则与许可。交换装备时若旧装备无法完整放回自身库存，应拒绝该次交换并保留原物品，不以溢出掉落或删除代替整理。当前支持点击、快速移动和热栏/副手交换；拖拽和双击收集尚未开放，属于实现缺口，不是永久规则。

UNKNOWN 涉及的存活箭保持持久隔离，核对证据之前冻结并禁止产生新效果。结束原会话不释放它到原版，不自动销毁、不加超时、不重放碰撞；历史来源继续保留。该修订优先于普通已知箭在无活动调度域时恢复原版推进的规则。
- 操作被中断时保留已发生的真实效果；不会为了“取消动作”把已经改变的世界整体倒回。
- 相同输入重试不应再次扣费或再次造成伤害；重新连接不能自行恢复资源。
- 保存会话和必要行动记录。重启后若无法确认某效果是否已经发生，显示/记录未知并释放不确定的会话或行动控制，不再次施加来碰运气；涉及存活箭时仍遵守上述隔离例外。
- 恢复不为会话强制加载成员区块；首次本应安排环境步骤的机会仍不能核对证据时，应按未知处理并释放。
- 结果默认保留七个游戏日，以跨重启累计服务器 tick 计时；暂停期间继续计时，快进不缩短，仍有效的重试或因果引用延长保留。
- 非投射物的跨 tick 操作累计七游戏日仍无自然终态时，以未知结束并释放该操作控制；这不对箭矢增加寿命上限。

当前全部活动会话走统一恢复审计；历史文档报告过写盘重读，但不等于本次复验。当前不承诺重启续战；活动会话重启、崩溃对账、归档与完整客户端恢复尚未通过，合法快照恢复回归不能替代上述运行证据。

## 12. 界面与当前按键

**2026-09-26 回合 HUD 生命周期修订：**打开暂停、背包、设置等原版菜单时隐藏回合界面，关闭后恢复；隐藏不结束 Encounter，也不丢弃规则投影。F1 随原版 HUD 隐藏。打开聊天时保留底部行动栏，暂时收起先攻、日志及浮动面板；聊天消息、输入栏和命令补全上移到行动栏上方，输入归原版聊天独占。退出会话后恢复原版聊天位置。回合界面文本不可选中。

**目标界面（R58–R60）：**能看到先攻顺序、当前单位、行动资格与剩余资源；显示统一场地、可达格、路径和目标；操作拒绝与部分结果可见。

**已确认的目标式交互修订（本次统一到073919文档）：**进入有效会话自动启用独立焦点镜头。镜头不改变身体位置、朝向、物品或资源。输入优先级为 Screen/输入框、同意弹窗、战术 UI、世界；失焦停止合成输入。

- 空闲左键地面提交移动，左键实体检查；右键对象打开绑定该目标的菜单。
- 选武器准备攻击，选方块准备放置；服务端确认物品后左键选择目标。多能力物品显式选择行为；选择、查询和镜头不收费。
- Targeting 的右键/Esc 取消预览；未提交、等待查询回复的目标（包括空闲左键地面移动）同样可取消，迟到回复不得重新提交或恢复菜单；菜单右键/Esc 关闭。已提交计划取消须等待服务端终态，已发生移动和已接受动作不退款。运行中拒绝换槽。
- Esc 每次只消费一个层级：菜单/预览、运行计划、物品面板、游戏菜单。Screen 和同意弹窗优先。
- 菜单项提交菜单绑定的目标，不重新采用菜单下方射线。实体检查不限于可攻击成员；执行资格由服务端适配器决定。

## 15. 目标式行动的费用与执行合同（整合已确认修订）

- 候选阶段的当前成员可以使用剩余移动预算、执行非敌对世界交互。选择目标或接近目标不触发战斗；首次合法攻击实际开始时激活战斗、重掷先攻并消耗动作。
- 一个计划绑定所选能力、目标、物品槽及完整堆栈值。服务端寻找合法执行位置，必要时先移动，再复验并执行。目标失效或移动时中断，不自动换敌人；取消保留已经产生的移动费用。
- 放置、破坏和物品使用在原版接受行为时消耗一次动作。未处理或开始前拒绝免费；接受后的持续行为中断不退款。攻击合法开始即收费，未命中及零伤害不退款。无法确认副作用的恢复结果为 UNKNOWN，不盲目重放。
- 世界方块自身交互免费，但不能回退到免费使用手持物品。开箱免费；只有本人回合、仍在交互距离且菜单有效时允许普通存取。合成、交易和丢弃不在此许可内。
- 基础弓、弩和雪球使用独立攻击能力；蓄力和发射属于同一次计划。箭只支持普通弹药，附魔和特殊弹药必须明确拒绝。短暂投射物保留来源，在环境阶段继续模拟，不因结束动作失去归属。
- 镜头围绕独立焦点：WASD 水平平移、QE 旋转、滚轮缩放、中键拖转；空闲右键目标查询绑定菜单，Targeting 左键确认目标。镜头操作不移动角色。自动移动使用原版玩家输入、碰撞和服务器位移观察，不传送。

### 通用行为选择修订

玩家物品行为由服务端按所选目标、堆栈与手别提供，选项包含不可用原因。此处描述玩家交互，不要求未来 Mob 天生能力伪造物品槽。斧子的攻击与对方块使用、手持方块时的方块交互与放置是不同选择；不识别的效果拒绝，不自动改为近战。行为版本、目标、手别和完整堆栈证据绑定根计划，费用仍遵循上述规则。支持范围与待验收项统一见 G34。


## 16. 规则维护边界

架构评审可以要求区分选择与查询、当前许可与历史回执、动作效果与清理状态，但不能据此改变本人回合免费整理、无锁定场内退出、非敌对 Mob 可轮转移动等已经批准的规则。目标式攻击不可退回“先开启手动移动，再只攻击附近对象”。

相机问题 CAM-01 仍仅为用户报告：观察高度不跟随地形，进入方块后出现进入地下的表现。根因和碰撞策略尚待实机核验，本轮不把推测写成既定机制，也不宣称已修复。

本轮未运行实际客户端、专服/双客户端或恢复验收；新的实现/支持范围结论只在01和02更新，不在本规则文件不断追加“本轮已通过”段落。
