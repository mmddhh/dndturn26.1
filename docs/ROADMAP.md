## 内容接入边界

召唤、附加条件、充能、Guardian 引导及 Boss 动作尚未进入通用执行器。具有附加条件的已有怪物仍使用纯伤害档案；Witch、Evoker、Shulker、Guardian/ElderGuardian、Dragon/Wither 的运行 actions 暂空，基础定义不表示专属玩法可用。充能定义不按固定回合冷却解释；超过 32 个动作的定义不授予通用动作。全部自然伤害和第三方特殊机制尚未统一支持。

旧记录引用的 `docs/data/vanilla-mobs.yaml` 当前工作树不存在。未接入设计需要从用户提供资料或 Git 历史核对；不把旧引用当作当前可用数据，不自动恢复旧文档，也不引用外部图鉴补玩法。

继续暂缓 PvP、HIDE、Enderman 定点传送、完整飞行/专属游泳/载具、Boss/大型部件玩法，以及未确认的流血/破甲/连击。WIP 中未定的产品选择保留确认边界。
