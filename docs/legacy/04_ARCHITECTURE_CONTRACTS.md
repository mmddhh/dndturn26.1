# DNDTurn：当前架构合同

<a id="package-ownership"></a>
## 包、命名与所有权合同（2026-09-30）

依赖方向为 `domain ← application ← platform`。domain 定义 Actor、Ability、Effect、AI、Encounter、控制判断及其值合同；application 编排快照编译、移动规划、调查与投影排序。纯命中／费用规则及被领域调用的 ResolutionContext、ActionIntent、ExecutionRequest 留在 domain，避免按目录名称制造 domain → application 反向依赖。密封 RuleEmission 与其实现保留在同一 domain.actor 包，以满足 Java 17 未命名模块约束。

| 名称 | 唯一职责 |
| --- | --- |
| Definition | 不随 Encounter 改变的冷定义 |
| State / Authority | 有明确 owner 的权威状态／唯一 writer 或 issuer |
| Snapshot / Projection | 脱离运行对象的不可变读模型／权威事实的只读投影 |
| Context | 一次调用或有界执行的短生命周期上下文 |
| Policy | 纯判断，不写状态、不签发许可 |
| Coordinator | 协调多个 owner 的流程，不复制权威状态 |
| Adapter / Registry | 平台语义转换／注册后冻结的映射 |
| Record / Receipt | 已发生事实的历史证据 |
| Permit / Lease | 有生命周期、范围和撤销条件的实时授权 |
| Effect | Actor 的 Buff／Debuff／Stack／Trigger 状态系统 |

`ConditionDefinition`／`ConditionRegistry`／嵌套 Condition 分别由 `EffectDefinition`／`EffectRegistry`／`EffectInstance` 取代；ActorRuntimeState 使用 effects，来源为 EFFECT／EFFECT_INSTANCE。`TriggeredExecutionRecord` 与 `WorldOutcomeObservation` 是执行证据，不属于 domain.effect。Minecraft 药效投影使用 EffectSnapshot.Vanilla；药效计时接管由 target 的 VanillaEffectSettlementState／VanillaEffectRoundController 持有，不能放回 common。世界写入 scope 使用 ItemWorldMutationScope，世界许可使用 OutcomePermit。

ServerRuntime 持有每个 MinecraftServer 的运行实例、世代及关闭生命周期；ActorStateAuthority 负责角色，EncounterAuthority 负责遭遇规则，ActionExecutionCoordinator 负责行动执行，ProjectionPublisher 持有发布序号／订阅，EnvironmentScheduler 持有当前世界步绑定及公平调度游标。EncounterRuntime 协调这些 owner，不持有它们的第二份状态。关闭、恢复及合并依照原有规则入口完成；迁移包不改变费用、非敌对移动、退出、未知结果或许可合同。

跨包通过有界命令和只读值协作；ActionHost、WorldOutcomeHost、VanillaEffectHost、ControlFacts 明确需要的能力，不把原 package-private 方法全部设为 public。世界扩展通过冻结的 WorldOutcomeHooks／CloudOrigins 注册，bootstrap 安装 builtin 的 creeper／skeleton／AI／近战实现；通用框架不导入具体物种。行动内部仍需共享有界执行上下文的适配簇可以一起迁移，后续提取须先定义其执行端口，不能直接公开可变 Execution。

EncounterPersistence 持有 SavedData 写入节奏、规则快照缓存及行动检查点／恢复证据。候选验证后才交由 EncounterRuntime 安装各运行 owner；持久化 owner 不持有 Entity／Level，不取得 Lease 或重放能力。运行时在服务器线程采样当前跨 owner 值，写入成功后才确认保存修订；SavedData 更新不代表立即落盘。终态检查点只读，后续对账追加证据；损坏候选禁止覆盖原文。关闭时沿用运行时先采样保存再释放控制的顺序。

platform.network／projection／spatial／observation 是客户端可消费的共享平台值或查询；不能引用 server 实现。Mixin 按接入的业务边界分包，并通过批准的窄 hook／policy 进入平台；不得直接读取 EncounterAuthority、ActorStates 或协调器内部。源码架构测试同时检查依赖方向、split package、路径与声明、具体物种反向依赖及 Mixin JSON 完整性。测试不替代实际注入及游戏运行验证。

这是源码/API 与当前检查点结构迁移，不增加旧格式别名、schema 版本或隐式兼容分支。旧检查点仍按当前结构及不变量校验，拒绝时保留原始证据。具体迁移及验证见[包与所有权记录](../version-differences/neoforge-26.1-package-ownership.md)。

## 服务端默认能力合同修订（2026-09-30）

当前用户明确指令覆盖旧的精确类型准入合同：Mob 通用受击／近战／AI 和物品、方块交互使用专用适配优先、通用入口后备，不以精确 Java 类、实体种类或原版命名空间白名单决定是否提供通用能力。客户端表现注册不随之扩大。新建独立扩展注册器不隐式安装全局后备，内置注册器显式提供默认能力。

物品查询仍为纯发现；提交调用原版 use／useOn／interactOn，按实际接受与观察结算。同步 Level 方块写入口核验真实位置并有界扩展观察，不能声称覆盖任意模组直接区块写入、BlockEntity 内部字段或延迟传播，更不能声称可回滚世界副作用。默认可用不改变费用、关系、时间、加载与保护合同；未知结果不重放。


## 门禁查询与执行准备合同

Effect 策略只消费已捕获事实，不签发许可或修改预算。纯模拟查询不得处理碰撞、移除实体或登记效果；执行准备分别返回继续、等待、接触已处理、隔离、结束，由真实 owner 完成对账。同 tick 已处理接触不能因步骤产生新修订再次执行。受击合同独立注册并由发现和执行共用；可受击不自动授予自主攻击、移动或 AI 能力，未知 override 保持明确拒绝。

## 免费调查合同（2026-09-29）

调查是独立只读查询，不是选择并查询或能力执行。InspectionService 在服务器线程核验当前连接／实例、世代、双方成员归属、加载与视线；ActorStateService 只捕获策略声明事实，InspectionPolicy 接收纯值观察者及裁剪事实，输出有界 InspectionView。角色、Encounter 与原生事实各自保留所有权。内置策略仅公开名称／类型和已公开遭遇状态；扩展输出默认隐藏，显式注册读取集及输出字段，冲突拒绝，在共同设置时冻结。旧可信 Inspection/inspect API 保持兼容，其默认空投影不作为网络入口。

调查请求不携带可信观察者、读取字段或费用；调查与战斗载荷均使用 loader 必需的固定注册标识 dndturn，不维护协议递增号。最多32字段、每项文本256字符、载荷16KiB；每玩家连接身份按20服务器tick窗口最多4次查询，服务器每tick最多32次处理。重连不重置同UUID的剩余窗口，避免绕过限流。超限明确返回，不排队或自动重试。客户端调查状态独立于行动选择，关闭／新请求／会话和实例变化失效旧请求；面板是标明采样时点的快照，不进行自动刷新或知识持久化。未知目标、隐身、遮挡及捕获异常统一为不可用，错误不回传隐藏字段或内部异常。

## 角色状态增量合同（2026-09-29）

2026-09-30 明确：Effect 实例 `revision` 表示状态变化，`grantRevision` 表示授予证据代次；期限推进／刷新不撤销仍有效的来源。只读 native-backed 投影以 amplifier+1 表达公共 rank，amplifier 单独可读，保留原生 tick 期限（-1 表示无限），不建立第二药效 owner。反应同波冻结输入，按事件顺序／实例／触发 ID 排序；层数增量可交换合并，移除冲突、不兼容替换和透支拒绝整波。每根深度16、事件256、变更512，超限保留已提交状态并隔离。纯事件派发账本与世界能力执行证据属于不同合同，不以纯状态回执证明爆炸等副作用可安全重放。

ActorStates 是角色纯状态的唯一写入口，服务器 ActorStateService 核验线程／实例并协调捕获与保存；ActorSnapshot 仍无存储权。Learn/Prepare/条件/资源命令绑定操作与预期修订，先校验候选再提交；重复 ID 同负载返回原结果，不同负载拒绝。周期流逝不更换授予代次，移除／重新授予和准备变化会使旧证据失效。持久 Actor 数据与 Encounter 数据分开保存，不承诺跨世界原子恢复。

模拟空事件压缩合同（2026-09-30）：仅对已完成、单个、规范身份的 SIMULATION_STEP 事件，且没有关联规则回执／世界调用、没有转换／其他目标／cause 时，以角色的精确序号区间保存完成证据。区间不能跨越缺口；恢复核对角色时钟，重试返回完成且不执行回调，修改负载拒绝。待决、失败、有副作用证据及其他事件保留原记录；此压缩不替代七游戏日引用感知归档。

既有容量故障只在饱和历史全部完成且确有可压缩记录时生成恢复候选。限无持久授予／资源／条件、无世界调用、无未完成派发、历史命令仅为空命令或时钟推进的角色；服务器生命周期每 tick 至多检查8名候选，不加载缺失实体，当前实例及规则编译通过后追加保留原故障的恢复证据并解除隔离。旧异常类名不能证明原始抛出点，因此恢复依据是完整检查点与当前无效果状态的重新核验；不重放漏失事件、不退款、不恢复旧许可，其他隔离继续保留。

条件及持续能力只修正规则统计，不能改写原生 effective attribute 或资源余额。条件声明时钟、叠加、死亡及保存策略；边界先推进条件；移除、到期和降层事件使用对应实例转换前的授予证据，其余来源消费冻结波次快照。该证据仅授权这次反应。持续子授予继承真实来源 owner，展开有界且拒绝环。触发／周期后端输出纯状态差量或带来源的触发调用；后者必须重新经过规则、准入、费用和受限执行器。输出本身不是世界许可，也不能自报免费攻击。

触发谓词与能力执行分别声明读取合同：谓词消费本事件边界的冻结事实，执行可用性由后续 resolver 捕获与校验。付费触发在资源接受边界之前完成可确定的过程容量／控制／驱动支持校验；待接受效果的资源占用由规范操作推导，不另建余额。命中部件同时绑定根实例与部件实例，根未替换不能替代部件复验。

当前修正顺序为基础值加 ADD 总和后乘 MULTIPLY 总积。2026-09-30 起修正显式区分 CONSTANT 与 PER_STACK，后者让条件层数参与对应总和／乘积；旧构造器默认 PER_STACK。AC／减伤在最后取非负整数，溢出拒绝。原生已应用装备／药效不会重复叠加。此合同只定义新注册修正接口，未增加内置 buff 或改写现有无修正时的公式。

Tactical Effect 使用 EffectDefinition／EffectInstance 源码名称，覆盖此前保留 Condition 的命名约定。Actor 局部归并 key 由定义指定为单目标、来源 actor、来源 actor+ability 或应用 operation；实例 UUID 只标识实例，不控制叠层。rank 不参与层数缩放；非 REPLACE 的 rank 冲突明确拒绝。AddStacks 受最大层数及溢出策略限制，ConsumeStacks 不能透支，零层删除，RefreshDuration 服从独立刷新策略。grant 可声明最低 rank／层数，同一能力版本不能因条件不同而重复声明。候选状态与所有变更校验完成后再提交，原快照不可变；此状态提交不授权任何原生世界效果。

ReadContract 区分 actor/target/world，EncounterInput 只给出本次源／目标成员与阶段身份。命中计划只解释已捕获骰值，只有执行接受后的采样方推进 RNG。回合时钟由规则转移通知，查询／网络投影不修改角色状态。CharacterSheet/Spellbook/Inspection 是投影；默认调查不可见，当前没有新增客户端界面或开放完整服务器快照。

扩展注册启动时冻结，未知定义保留持久来源并明确不可用；不热替换正在执行的语义。新增接口编译与既有 GameTest 运行不等于扩展闭环、真实重启或新条件场景验收；当前事实及限制见[版本记录](../version-differences/neoforge-26.1-dnd-data-model.md)。

## DND 数据模型迁移合同（2026-09-29）

Definition由冻结注册表持有；Grant分别表达历史来源、生命周期owner和当前证据；Binding是一个定义经一个grant可供选择的只读组合。Wire TacticalIntent与服务端AbilityInvocation/ExecutionRequest分开，均不等于许可。Definition的操作种类、目标政策、ActionCost与commit point分别表达，native provider不能在观察时自报免费。

ActorSnapshot仅是某次捕获的规则输入；CombatantSnapshot组合Encounter只读成员视图，先攻结果和动作/移动/反应资源仍由CombatEngine所有。原生生命、库存、位置和效果保留原owner；没有真实DNDTurn状态时不为填满草案结构建立第二套可变Actor数据库。SnapshotCompiler只归一化已声明事实，原生effective属性不再额外叠加装备贡献。

ReadContract使用类型化键和有界不可变标量。缺失、unsupported和unresolved显式表达；合并事实不允许覆盖同一key的owner。resolver接收限制后的快照/事实，不持有Minecraft上下文。NativeAbilityFacts与native executor分别注册，内置实现可以共享实例，但不能因此重新合并规则与执行权威。

长执行在不可逆边界重新捕获，合法自身消耗更新运行证据，原始规范意图与历史不回写。持续步骤是否已开始由待决根/子操作证明，不能让客户端选择continuation逃过资源检查。执行请求保存捕获版本和来源值；恢复不重建旧resolver对象、不将请求当作新许可，也不自动start未知世界效果。

2026-09-30 后续修订：移除 schema／protocol 格式版本，不建立迁移分支；按当前结构及不变量校验，失败保留原文。剩余原生复合事实、Actor长期状态、扩展和运行验证统一登记[DM-01](../02_GAPS_AND_CONFLICTS.md#dnd-data-model)，不以本合同宣称完整草案已实现。

## 稳定架构合同

### 14.1 唯一权威、身份和数据载体

CombatEngine唯一裁决成员、关系、阶段、先攻、资源和规范终态；target拥有原版对象与受限执行。运行Lease、域/held所有权、历史、实时EXIT授权、客户端选择及表现各有明确生命周期，拆类不建立第二份账本。成员域、空间模拟域、效果来源域分开，合并别名不是自动获得全部权限。

common为Java17纯值/规则，不引入Minecraft/loader/Mixin/平台Codec/渲染；固定target承接平台入口。Wire DTO、服务端规范意图、运行上下文与持久检查点分开；不能反序列化Entity/Navigation/Brain/连接继续执行。异步只用冻结纯值，主线程提交前重验实例/版本/权限。

### 14.2 六层能力语义

| 概念 | 合同 |
|---|---|
| 定义 | 能做什么、目标/规则/执行约束；注册不代表人人拥有 |
| 来源绑定 | 装备/自身/状态为何赋予能力，以及代次/失效条件；不等于许可 |
| 当前可用性 | 原地可执行、需接近、缺目标、规则阻止、不支持、评估未完成分别表达 |
| 调用 | actor、能力ID/版本、来源、目标、有限参数和原始请求证据保持稳定 |
| 许可 | 当前世代、执行者、操作/阶段、目标/范围、预算和次数；非空UUID/同域不够 |
| 运行记录 | 已发生的步骤/效果/费用/释放；不是定义或UI预览的可变副本 |

同源可提供多个行为，玩家也有自身能力，Mob也可有装备；不得重新固定“玩家=物品，怪物=天生”。物品内容哈希不等于实例身份；合法自身消耗推进预期证据，外部换物仍需拒绝。纯发现/评分不切槽、不导航、不造成效果或消费规则随机流。策略提出意图，执行器不偷偷换敌人或默认结束回合。

### 14.3 执行、结果、未知与扩展

共同后端执行规范调用，必要接近/到位复验/效果观察。规则原子提交不承诺Minecraft世界事务。效果、费用提交、取消请求、幂等release分开；已确认效果不被清理异常抹去，控制不安全则隔离/停止继续。父子汇总不重复收费/伤害，历史结果不回写，UNKNOWN不盲目重放。

行为应声明必要读取依赖、直接作用范围、执行入口、观察和中断/恢复。未知override/扩展组件保守拒绝；不哈希整世界、不事后setBlock回滚冒充未发生。原版攻击者特殊钩子与受害者hurt不同，额外效果逐项审计，不放开整个Mob.tick或Goal.tick来获取意图。

扩展注册要有稳定ID/版本、侧/线程、匹配/冲突、冻结/重载及字段/执行通道所有权；内置也使用注册。运行计划不被同名新驱动偷偷接手。独立compat必须在独立Java包、仅公开有限API下成立，不借核心package-private、不开放整个service或反射。库不构成同JVM其他mod的沙箱，未覆盖路径明确限制。

### 14.4 时间与显示

世界日程、有效模拟步、行动进度、AI记忆/冷却、400/100窗口、七日累计服务器计时、装饰时钟分别定义；不能统一替换gameTime或假定停止tick就冻结所有绝对期限。环境与06共用现有时钟/来源，不另建竞争时钟。

表现消费事实和去重事件，动画不裁决伤害/耗物。AGE offset当前按实例/renderer生命周期持有，其余通道按合同交还；不要求绝对年龄插值回原生制造倒退，也不改真实tickCount。多次渲染只读同一采样，不重复粒子/关键帧。CameraRig只管焦点、距离、地形与避障，不改真实身体。

### 14.5 预算、诊断与验证

当前已有预算保护，但累积工作必须能最终完成；延期保留进展，源依赖变化再有界失效。单包/单次搜索限额不等于多会话公平。错误以机器码/重试建议驱动，不解析文案；控制与效果失败不可被普通网络重试重演。

固定版本seam核验完整签名、调用顺序、取消与物理侧；参考`.109`不代表`.84`注入通过。保留gameTest隔离，诊断不得改变生产授权。验证分纯值、平台、真实输入/双客户端、当前格式重启/故障及性能；方法存在/编译/历史通过不转为本轮通过。允许测试摆位置，但不以setPos模拟待测移动；删除测试不得当作修复。各target共用common构建输出时串行运行，不能把文件竞争误判为规则测试失败。

## 玩家物品使用与延迟接触

自身、实体、位置及瞄准目标须明确绑定；方块自身交互、对方块使用物品和实体交互分开，不以通用右键回退选择无关行为。持续使用按[已确认规则](03_PLAYER_RULES.md#player-item-rules)在当前回合完成，执行器不得自动END_TURN或逐tick重收动作。未知组合需专用适配，不因为匹配父类、同域或处于执行窗口而获得权限。

实体生成须在不可逆写入前校验有界读取依赖及实际作用范围；加入事件不等价于成功插入。同步作用域只桥接本次执行，结束后仅保留不可变身份和观察值，不长期保存Entity。原版已接受但效果不明时留UNKNOWN，不用失败重试重放。

发射与后续接触是独立生命周期。接触关联已确认发射、来源、当前环境许可和实际影响位置；operation去重不替代有限许可。延迟接触不消耗下一回合动作，父子效果不重复汇总。死亡／离场与终态发布按同一执行边界收束；未知结果的隔离不随会话结束自动撤销。

轨迹是只读、有界的名义预测，按弹种处理发射参数、重力及碰撞顺序；不创建或补跑真实实体、不消费规则随机流、不作为命中保证。实际支持和未完成的证据字段分别记01／02，不以本合同宣称所有效果适配已具备。


## 参与者回合过程

规则权威确认唯一回合结束身份后，平台先结算所属参与者过程与效果，再扣期限、清理死亡并轮转。普通结束与自动结束共用入口；重复请求返回原结果，不重复推进。效果、费用和释放独立留证；未知世界效果不得重放。会话捕获roundTicks，新过程捕获所属会话值，合并不改既有过程基准。恢复只安装当前格式、已核验的值，不反序列化Goal、Brain或旧实体实例。

## 公开执行端口与托管状态

装备能力可组合真实装备证据与标准 Tactical Effect 政策：分别核验 actor 实例、装备地址／写入代次／内容、效果实例与 grantRevision、政策和原生驱动版本。相同内容的替换物品不天然保留旧许可。组效果在生命周期命令边界安装／释放，查询不隐式安装；效果只提供声明的装备政策，动作费用仍由规则权威裁决。原生驱动的物品零消耗也需观察。原生类型匹配与方法调用留在注册适配器，标准 Actor／planner／执行调度不添加物种分支。

外部适配器仅取得绑定既有计划的回调上下文，离开回调或计划终止后撤销。端口执行前核验线程、actor实例、当前计划与行为版本；执行目标、来源和成本来自已绑定调用，调用者不能换目标或自报费用。准备、取消与释放回调不具有世界效果执行权。

有界运行状态由计划运行所有者持有，禁止平台对象进入持久检查点。释放成功或实例退役时清空；释放失败时保留必要状态供有界清理重试，隔离新的执行。清理重试不重放世界效果，不修改已发布根结果；成功后追加对账证据。当前实现的具体端口范围记01，其他效果与恢复缺口记02。
