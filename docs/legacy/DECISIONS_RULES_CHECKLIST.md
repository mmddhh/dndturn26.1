# DNDTurn 游戏规则与顶层设计

本文件只维护有效规则、稳定 D/R/H/X 编号和明确修订，不记录实现进度或测试通过宣称。功能缺口、规则疑点 Q 编号和待验收场景统一见 [M3 acceptance](M3_ACCEPTANCE.md)。程序约束见 [AGENTS.md](../AGENTS.md)，设计理由见 [架构决策](COMBAT_ARCHITECTURE_DECISIONS.md)。

规则来源为 [dndrule.txt](dndrule.txt)；以下显式修订优先于原始表述。源码不能反向替代未定义的规则；冲突须在 M3 文档列出后明确决定。

## 0. 有效设计与修订顺序

第 0.6 节汇总 2026-09-23 后续决定，第 0.7–0.10 节汇总 2026-09-24 至 25 日修订；这些明确修订覆盖前文与原始规则的相冲突表述。

### 0.1 场地：统一范围、固定锚点、连线扩张、内部填充

- 战术参与范围与模拟暂停范围使用同一场地定义，不采用“圆柱选人、整区块暂停”的双重边界。
- 场地由多个相同规格的竖直圆柱及其连接、填充区域构成，几何采用连续点查询，方块离散仅用于取样和显示。建立会话时，捕获**发起时发现范围内所有实体的中心位置**作为几何锚点；不能仅采集已判定为参战者的玩家/Mob。
- 几何锚点与实体后续位置分离，固定到该次场地版本结束。实体移动、离开、死亡或外部发射者后来加入，不因此自动移动锚点或扩张原场地；合并提交时按首次建场规则重新发现和采样，发布新场地版本。
- 任意两个锚点之间的连线，沿线都覆盖相同规格的圆柱；两个同高度锚点的水平轮廓因此为胶囊。
- 填满实体围合范围的内部，不保留内部空洞，也不是仅绘制所有连线的“管网”。在统一半径的水平投影中，可准确表达为：**锚点的二维凸包向外扩张一个半径为 r 的圆盘**（`conv(P) ⊕ disk(r)`）。一个点为圆盘、两个点/共线点为胶囊，多点通常为圆角凸多边形；离散化后体现为方块边缘，并非严格直边多边形。
- 上述水平表达是对“全部连线＋内部填满”的几何解释。不同高度锚点统一使用最低 Y−16 至最高 Y+16 的水平顶底面；方块按自身中心、实体按自身中心查询。初始水平发现尺寸与笔刷半径保留显式参数，见 Q01/Q13。
- 实体跨出边界以实体中心判定，不要求整个包围盒完全越界。出界是否立即退出会话、迟到加入者如何参与属于下一阶段成员生命周期问题。
- 用于生成场地的“所有实体”不意味着所有实体都成为有先攻/动作的参战单位；几何锚点、候选单位、环境对象分别分类。

### 0.2 暂停与外部变化

- 区域内只暂停**模拟推进**，不承诺区域状态与外界完全隔绝。外界允许改变区域，但其输入须经过首次进入/作用边界的分类与相应规则。
- 外来箭矢首次进入区域时，纳入该会话的环境回合或候选对象管理；不能在仍按外部自由 tick 的状态下一口气越过区域并结算内部命中。攻击证据见第 0.10 节。
- 该箭矢首次入域即受会话调度约束；当其目标锁定或扫掠碰撞明确构成对成员的攻击行为时，在伤害判定前将可识别的发射者并入同一战斗会话。闪避、未命中、零伤害不取消介入；仅穿过场地且未构成针对成员的攻击不触发介入。发射者在场地外不取消因果归属，也不据此重新生成既有场地。
- “环境回合推进”仅是调度分类，不能抹掉箭矢的原发射者或把箭矢伤害自动当成无来源自然伤害。PvP 拒绝，跨会话与死亡/离线发射者按第 0.10 节处理。
- 外界流入的流体等允许进入并影响区域，但进入时必须接受区域规则，后续更新不能继续绕过暂停。进入更新中哪一部分算外部改变、哪一部分等待环境回合，留到边界案例细化。

### 0.3 环境回合按明确分类推进

- 环境回合只推进明确归为环境的对象，不默认解冻所有参战者、非参战生物或所有未知来源。
- 初始范围：方块、红石，以及没有生物/玩家行动 owner、没有明确目标的部分投射物；方块和红石的“推进”指其模拟更新。
- 外来投射物首次进入时需要分类；已登记的存活投射物保留因果 ownership 并按环境回合调度，原 owner 死亡或离线不改变调度。它们不是把所有未登记对象默认归为环境的理由。
- “无来源”在此指没有行动 owner，不等于删除已知发射方块、位置或其他因果信息。“无目标”不是单凭原版实体没有 target 字段就可以认定。
- 发射器发射的箭矢可作为上述类型示例。原版投掷器通常输出 ItemEntity 或向容器转移物品，不是发射箭矢；其产物是否计入环境运动白名单另列待定，不按示例名称直接混为 Projectile。
- 初始方块/流体模拟通道按第 0.6 节执行；其他环境对象按第 0.9 节的封闭白名单处理，不通过“其他来源全放行”推定。

### 0.4 攻击、击退与投射物生命周期

- 在已有回合制影响范围内，攻击行为就触发正式开战，不以命中或产生生命损失为前提。它修订旧“候选阶段敌对伤害后开战”；不恢复范围外 Mob 自然索敌自动创建会话。
- 暂停目标受到合法击退时立即移动，不等自己的回合或环境回合；该响应不自动授予自主攻击/移动权。
- 所有战术击退路径受 gamerule/config 控制；默认一次战术攻击无击退。启用后的合法击退仍按原版碰撞立即响应。
- 不设置模组主动投射物超时，不因经过固定数量的服务器 tick 强制销毁、失活或改归属。原版实际运行中的碰撞、消失及寿命机制保留；暂停不继续消耗对应模拟寿命，现实存续时间可无限延长。
- 投射物保留原 owner 和源操作的历史因果记录，当前调度归环境回合；owner 死亡或离线也不改变这项调度，不等待 owner 行动窗口。
- 投射物寿命按固定版本各类原版生命周期处理，不采用统一 600 或 1200 tick 常量。
- 存活投射物保留因果 ownership，作为环境投射物按环境回合推进；行动结束、owner 死亡或离线及会话合并均不等待其销毁，也不主动施加模组超时。见 Q08/Q16。

### 0.5 移动以 tick 计费

- 移动费用以 tick 为最终计量单位，不根据实际距离或格数换算消费；距离只作为设计校准、路径显示和结果观察，不作为运行时扣费依据。
- 原“基准步行 6 格”、疾走“增加 6 格”、水中“每格双倍”、起跳“一格”等表述仅保留为历史设计参照，不能直接当作游戏运行时的距离费用公式。相应 tick 预算/倍率/一次扣费方案按第 0.6/0.7 节执行。
- 受阻且实际位移为零时免费，同 tick 多个移动包只结算一次；这是第 0.7 节的明确修订，不能再列为未定，也不按位移长度换算费用。

### 0.6 2026-09-23 后续用户修订：完整游戏循环的实施语义

以下决定修订上文相冲突的待定表述，但不表示相应功能已经实现：主动移动按获准控制窗口计费，普通 tick 扣 1、水中扣 2、起跳额外扣 1，空中仅存在主动水平输入时扣费；被动位移和位置纠正不扣。候选阶段首次合法攻击消耗一次动作后触发开战，重掷不返还该动作；非法请求不触发开战。移动/环境预算的可覆盖配置初值分别为 28/20 tick。

初始环境白名单分别门控计划方块/流体 tick、随机方块 tick、方块实体与 block event；未知实体不因处于环境阶段而自动推进。成员死亡、掉线、换维度或卸载时移除该成员并释放其控制；最后一名成员离场时结束会话，投射物保留历史因果。外来箭矢的参战时点按 0.2 与 R68 的修订执行；若发射者已属于另一会话，进入合并流程；PvP 仍拒绝。

多人同意开启后，请求期间参与名单随范围变化；仍在名单中的玩家保留已提交同意，离开者的同意移除，再进入须重新同意。请求自发起起 20 秒失效，当前名单全员同意时固定成员并建场。无法安全授权或接入的战术效果必须在不可逆副作用前明确拒绝并说明原因。开发用建场配置初值为水平发现 16 格、上下各 8 格、场地半径 8 格、最多 16 区块与 64 锚点；这些值仅是可覆盖的开发预设。

### 0.7 2026-09-24 修订：零位移计费与实验原型范围

获准移动的服务端 tick 只有在观察到实际主动位移时才收费；受阻或零位移免费，同一 tick 多包只结算一次。普通移动按第 0.6 节收费；距离长度不参与换算。骑乘、特殊移动与复合位移归因见 M3 文档 Q06，不撤销已经明确的水中、起跳和被动位移政策。

允许在完整 M4/M5/M6 验收前，以单独的默认关闭 `prototypeEnabled` 配置提供普通玩家按键原型。该范围仅允许发现区内单玩家与一个 Zombie，拒绝另一玩家、重叠会话和不能安全授权的效果；这不改变正式战术入口的验收门槛。

原型的局部暂停承诺范围为计划方块/流体 tick、随机 tick、方块实体、block event 和实体移动。立即跨界邻居更新、天气等后续边界集中在 M3 文档 E03。原型选择内存 held-tick 恢复：正常退出、卸载、停止时交还原版并保留剩余延迟，不承诺进程崩溃后保留全部更新；正式会话持久化仍按 R63/R64 的目标执行。

### 0.8 2026-09-24 修订：首次攻击优势的 Encounter 范围

R17 的“首次”按每场 Encounter、每名发起者分别计算。首次合法 ATTACK 登记即消费资格；判定前在服务端捕获受击生物当时的 target，若未以发起者为 target，该次命中检定获得优势。未命中、取消或开战重掷先攻均不返还资格；未通过授权的请求不消费资格。新的 Encounter 重新计算，候选阶段和正式阶段共享同一次资格。

### 0.9 2026-09-24 修订：M3–M6 剩余边界

- 成员中心普通跨出固定场地不自动退会；空间门控关闭其主动行动，既有行动租约结算并释放。主动离场及死亡、掉线、换维度、卸载仍按生命周期规则退出。可识别的外来射手入会后即使仍在场地外，也保留因果归属和成员资格；入域前不能开启主动移动或攻击。
- 同一 tick 混合主动输入与击退、载具或位置纠正而无法证明主动位移贡献时，该 tick 不收移动费用，结果记录混合归因；未定义的骑乘与特殊移动不获得正式移动许可。
- 首版正式主动移动许可只覆盖普通步行、跳跃和水中移动；骑乘、鞘翅、旋转冲刺及飞行不使用该许可。租约期间切入特殊模式即结算并释放，无法拆分的同 tick 主动与特殊位移不收费。原版合法强制位移与位置纠正仍按来源记录，不能借特殊模式开启未经授权的主动移动。
- 持有有效盾牌即获得 AC＋2；只有实际举盾且战术攻击被接受时才桥接一次盾牌耐久，取消、免疫、零伤害及请求重试不损耗。武器属性保留有限浮点输入，按战术减伤与暴击后对最终伤害向下取整。
- 重叠的待同意请求自动合并；仍在动态名单内的同意保留，合并请求沿用最早发起时刻的 20 秒截止。全局冻结期间保留局部会话，但不推进移动、环境或新跨域效果，未实际执行的预算不扣。合并 Encounter 保留成员已消费资源、反应和原有资格，不刷新本轮预算。
- 已登记投射物按环境回合调度并保留历史来源。无法识别发射者的箭矢构成无发起者战术攻击：碰撞后做 d20＋5 对 AC 的命中检定，无发起者优势或动作资源；伤害只读取箭矢固有伤害和捕获的弓附魔增伤、药水箭组件，不按速度追加伤害。伤害、状态、击退等子效果逐项事前授权；任一组件不能安全授权时，在碰撞副作用前拒绝整次命中并发布原因。
- M4 环境首版只承诺逐类确认的封闭白名单。外界流体首次跨界写入属于允许的外部变化；区域内后续计划更新与传播只在环境步骤推进。天气、世界生成及无法可靠分类的即时更新不纳入首版承诺，跨界不可授权效果在副作用前拒绝。
- 恢复时不强制加载成员区块；恢复后首次本应安排该会话环境步骤的服务器调度机会仍无法核对证据时，发布 UNKNOWN 并释放控制。七游戏日归档按跨重启持久的累计服务器 tick 计算，暂停期间继续计时，快进不缩短期限；仍有效的重试和因果引用延长保留。
- 借机攻击在离开攻击范围前暂停该步，反应者可选择物品栏武器并确认；默认等待最多 100 个实际服务器 tick，掉线或回合结束视为放弃，随后恢复移动。
- 首版环境实体白名单不纳入投掷器生成的 ItemEntity 与火焰。后续逐类纳入前，必须有可核验的来源、owner/无 owner 证据和生命周期调度边界；不能仅凭实体类型放行。
- 非投射物的跨 tick 操作累计七个游戏日仍无自然终态时，发布 UNKNOWN 并释放该操作许可。期限按跨重启持久的累计服务器 tick 计算，暂停期间继续计时，快进不缩短；此策略不改变 R32 对投射物不设模组主动超时的决定。
- 首版不承诺门控即时红石、活塞和其他未分类邻居更新；后续若纳入，须逐类定义进入时授权和实际模拟阶段。区域外照常执行，已识别的跨界不可授权效果在副作用前拒绝。

### 0.10 2026-09-25 修订：外来箭矢的攻击证据

- 没有显式目标的箭矢，在原版运动段的扫掠碰撞明确指向会话成员时即构成攻击，先于伤害成功判定；仅穿过场地、没有目标锁定或成员碰撞，不使射手参战。例如箭擦过玩家但未形成原版碰撞，只按环境预算继续运动；碰撞已形成而战术 d20 未命中，射手仍已介入。
- 可识别且在线的射手在不可逆碰撞副作用前加入目标会话；若已属另一会话，先接入合并流程，不让箭矢绕过目标会话直接造成效果。已死亡或离线的射手不复活为可行动成员，保留可核验的发射快照作为历史来源。真正未知的射手没有成员动作或首次优势，但仍按第 0.9 节的无发起者战术箭矢规则结算。
- 发射快照、箭矢组件、运动段与目标碰撞证据中，凡该次效果所必需而无法可靠核验的部分，须在副作用前明确拒绝并记录原因；不能把伤害事件本身当作首次攻击证据，也不能凭箭矢曾在场地内就推断目标。

## 2. 游戏规则

以下为目标行为，不表示当前实现或验收状态。

| ID | 规则 |

## 3. 搁置的规则与功能

搁置是一项范围决定，不表示默认采用原版或默认取消。临时政策仍须遵循授权边界。

| ID | 搁置内容 | 当前有效政策 | 重新开启条件 |
| --- | --- | --- | --- |
| H01 | 自然环境伤害的最终战术规则 | 原临时拒绝保留；环境调度的箭矢不自动等于自然环境伤害，外来箭矢命中归属见 R68 | 定义自然伤害各类语义，投射物其他伤害细节留 P1 |
| H02 | 按伤害类型计算抗性减半、免疫归零 | 数值方向已有，类型数据来源未定义，暂不实现 | 确定类型体系、数据来源、叠加与原版硬免疫关系 |
| H03 | HIDE / 潜行行动 | 不恢复缺少检定与效果定义的旧行为 | 明确触发、检定、发现、持续时间、行动成本与解除条件 |
| H04 | 苦力怕战术引信限制、末影人定点战术瞬移 | 不增加战术特判；保留可验证的原版通用能力，但不默认允许此类生物在环境回合运行 | 定义能力、费用、目标范围、中断与反应窗口 |
| H05 | 飞行/游泳/大型实体/Boss 的专属战术规则 | 专属规则暂缓；不等于通用移动能力已经完成或禁止这些实体存在 | 定义特殊能力及其规则，验证通用能力与特殊机制的边界 |
| H06 | 其他三个 target 的正式战斗玩法 | 当前仅保持构建兼容 | 单独确定支持范围并通过对应版本完整验收 |
| H07 | PvP 玩法 | 当前禁止，见 R18 | 产品范围明确改变，并定义阵营、同意、伤害和反应规则 |
