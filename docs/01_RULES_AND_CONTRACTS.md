# 有效玩法与边界

本页只维护当前有效玩法与已确认边界，**不是功能完成声明**。实现与证据见[当前状态](00_CURRENT_STATE.md)，剩余工作见[路线](02_ROADMAP.md)，工程所有权见根[AGENTS](../AGENTS.md)。历史资料见[归档入口](legacy/README.md)，不以旧示例或实现缺口代替产品决定。

## 1. 战斗、field 与成员

玩家主动发起战术模式，保留正常 `/dndturn tactical` 入口。普通世界中 Mob 自然索敌不自动创建 Encounter；已有参战成员被 Mob 实际锁定时，该 Mob 可介入其 Encounter；允许实际原生仇恨驱动 Mob 对 Mob，普通世界不因此自动建场。参战 Mob 锁定未参战玩家仍不能绕过玩家同意。以原生目标提交后的最终值判定，取消索敌不产生入场；重复关系通知不刷新资格或资源。无敌人可保持候选轮转，环境参与者不被删除。

多人建场保留同意流程：发起者已同意，其他玩家确认，名单变化重新核验；最初请求起 400 个实际服务器 tick 截止。等待同意时世界正常，不先冻结名单。PvP 禁止；同场不自动使所有成员互相敌对。

**field 修订覆盖旧固定场地规则：**以参战玩家中心的水平凸包加默认 `regionRadius=35` 形成场地，竖向上下边界沿锚点高低各扩展 16。在玩家移动结束及回合开始重锚；成员可离开场地并在场外移动、发起合法行动，不因这一点自动退会或获得免费动作。

普通非敌对 Mob 不因位于场地内而进入先攻；成员是参战玩家及有实际仇恨/合法介入关系的实体。仇恨不是按物种生成，也不是永久每 tick 清空的缓存。同一实体至多属于一个有效 Encounter；同场目标变化更新关系，跨场介入走既有因果合并，不创建第二份成员状态。

场外攻击者（不在该 Encounter 的实体）攻击场内成员时加入并**立刻转为回合制结算**，不再静默取消原版攻击。近战与受支持的投射物命中即按回合制规则结算伤害，攻击者加入该 Encounter、建立双向敌对并重锚场地；被转换的原版攻击不再重复造成原版伤害。**不为免费插队**——攻击者仍按先攻排序，其下一次自身回合开始时消耗一个动作（复用 `preserveSpentActionOnNextTurn`），与是否命中、目标此后是否离开或死亡无关。近战统一经伤害边界（`LivingIncomingDamageEvent`）识别，受支持投射物沿用命中边界。攻击玩家（PvP）不在该合同内，仍排除。不得恢复延迟到下一合法行动窗口才执行首击的旧方案。

场地重叠仍触发既定合并。合并阈值和环境 hold 范围不与 35 半径解耦；两个单玩家平面场地在竖向等条件满足时，中心距离约 70 格以内可能重叠。不得为规避负载暗改合并规则。采样有加载/容量上限，不强加载，不把精确区域扩成整 chunk。

成员归属、当前模拟范围、效果因果来源是不同语义，不是三套任意半径。允许场外行动不自动取消桶、爆破、TacticalImpact 等效果范围和保护；逐类扩展前明确授权及观察。

## 2. 回合与费用

普通单位 d20 先攻，平手有稳定排序依据。每次自己回合取得一个动作、一个反应及一份基础移动预算；建场捕获 `roundTicks`，默认 30。开战已消费动作、后来成员资格及合并迁移不能被重掷/刷新抹掉。候选转正式在合法攻击实际开始或既定敌对边界发生，非法输入不激活战斗。

每个存续 Encounter **恰有一个**环境参与者，显示先攻 -1，但按类型永远在实体之后；不是普通 Actor，不占真实成员数，不领取动作/反应，不可攻击或调查。只有其自身有效预算完成才推进后续轮次；普通单位结束不额外赠送环境时间。

移动按实际获准主动移动 tick 结算，不按格扣费、不用 teleport/setPos 代替行走。可分段移动、行动后继续移动；被动推开不扣受击者移动。选择、查询和接近不是攻击开始；到位须复验。一次攻击完成不自动结束整个回合。

合法攻击实际开始消费一次动作，未命中/零伤害不退。物品、放置/破坏按各自原版接受边界收费；食饮、弓蓄力/弩装填等已支持持续使用在当前回合自动完成，只收一次动作，完成后仍可行动/移动/结束回合。特殊跨回合能力另有合同，不能统一套用物品规则。

## 3. 攻击及已定行动

基本命中为 d20+5 对 AC，自然 1 失手、自然 20 命中并暴击；优势两取高、劣势两取低，同类不叠加，二者同时存在抵消。保留当前映射，不借架构重构改数值：

```text
AC = max(0, floor(armor)) + (持盾 ? 2 : 0)
伤害 = floor(max(0, 选定基础输入 - max(0, floor(toughness))) × (暴击 ? 2 : 1))
```

原生属性、装备输入、规则计算和实际损失分开；不重复加装备、重复减伤或绕过免疫/取消/吸收。每场每名攻击者一次首攻优势资格：首次合法攻击登记前，目标尚未锁定攻击者则获优势；非法请求不消耗资格，未命中不返还。

近战使用已定一格各轴范围与可见性，允许先接近；普通远程保持六格，计划余量不扩大实际射程。更一般的原生范围须显式映射，不自动随属性开放。

| 行动 | 有效合同 |
| --- | --- |
| 空手 | 显式自身能力，不要求空槽/假拳头；基准伤害 1，局部原版推开输入 0.4；伤害与推开共一次动作，未命中不推，不触发无关手持物钩子；不承诺位移恒为 0.4 格 |
| DASH | 消耗动作，增加一份捕获的基础移动预算，不创建新 AP |
| DODGE | 消耗动作；到下次自己回合前，攻击者获得劣势 |
| DISENGAGE | 消耗动作；本回合主动移动不触发借机，不代表借机系统已完成 |
| HELP | 消耗动作；协助者邻接敌人目标，计划另指定同场盟友（同场玩家或主人关系确认的驯服生物），盟友无额外距离限制；敌对优先，中立生物不自动成为盟友，PvP 仍禁止；优势到协助者下次回合前，首次合法攻击登记时消费 |
| 借机攻击 | 主动离开威胁范围前暂停该步；反应者选武器/确认，消费反应；多反应者共享最多 100 实际服务器 tick 窗口，按稳定先攻复验，结束后按条件续走；被动推开不触发 |
| 方块自身交互 | 不收普通动作，必要接近收移动；不得失败后回退手持 useOn；开箱与存取/合成/交易分开授权 |
| 整理与调查 | 合法库存整理/换装沿既定免费规则；运行计划期间不换槽；调查免费且只读，不开放隐藏事实或无边界扫描 |

特殊投射物保留原版效果及物品消耗，合法释放收一次动作；伤害走既有战术结算，不重复施加原生伤害。延迟效果（包括珍珠传送、风弹位移）仍受过程调度、加载、保护和效果范围约束；实际接入程度见状态页。

普通弓箭按来源消费。Skeleton 组原生普通箭来源与不扣箭/弓耐久由标准效果/装备政策表达，仍耗战术动作；不改变玩家消耗，不由核心按物种特判，也不由此开放特殊箭/附魔。

## 4. 主动退出与生命周期离场

EXIT：自己回合且无执行中行动或反应窗口时，可主动免费退出。只计算本场存活敌对成员，任一方向敌对即算敌人；到最近敌人的水平直线距离至少达到捕获的 `escapeDistance`（默认 16 格），忽略墙体与高度差，与 field 半径独立。无敌人满足距离条件；无法确认敌人当前位置时拒绝并允许重试，不强加载。查询只给建议，提交重新采样和裁决。成功退出不传送、不清原生仇恨，不提供无敌或重入豁免；最后玩家退出后结束场次并释放其余成员。死亡、掉线、维度变化和卸载仍走各自生命周期释放，不受主动逃跑条件限制。

## 5. 世界与时间

世界普通更新、生命周期及未被托管的物理保持原版。主动控制、Navigation、技能执行和时间敏感过程分别门控；不能以长期关 AI 或全局冻结替代。被托管的 TNT 等过程按其专属已审计通道暂停，不把普通物理“默认放行”解释为所有危险过程自由进展。

同步直接交互和同步邻居响应可以立即发生；一旦进入计划延迟、周期、生产或危险过程，由指定 owner 的有效步骤推进，不继承最初玩家的行动窗口。红石无计划延迟可当场点燃 TNT，中继延迟先等有效步骤，TNT 引信随后按环境步推进。正常 80 步引信、默认每环境窗口 30 个实际有效步时，在第三个窗口内结束，不是下一环境回合必爆。

药效/着火等已接参与者过程按自己的回合末结算；剩余期限依捕获 roundTicks 换算。全局昼夜/天气等原版维护不搬成环境专用世界钟；已明确托管的区域生成/降雪结冰/雷击等单独实现和声明支持。

暂停保留队列剩余延迟、优先级、相对顺序及查询/去重。入域、出域、重锚、合并、卸载和重载移交唯一 owner，不补演真实等待、不重置相位、不重复推进。有效预算只扣实际获准步骤；全局 freeze、未加载或原生早退不算一步。同意窗口/借机确认等已明确真实时间超时是例外，不与模拟进度混为一谈。

## 6. 过程与 Actor 状态

沿用现有 Process 值和运行 owner，补阶段、时钟、检查点、有限执行驱动及对账。Actor-owned 与 Environment-owned 过程共享基础执行概念，但环境不伪装成 Actor。恢复已知阶段时不再次执行不可逆 start；证据不足保持 UNKNOWN，不凭可反序列化就认为可续跑。

Creeper：每次合法 Charge 耗动作加一层，三层在自身回合末 Effect 结算时原生爆炸；退出按比例映射原生引信并保留点燃状态，不恢复旧自动充能/衰减或满层后再等一回合规则。

Guardian：合法启动耗动作，准备/引导按捕获时间换算，默认三回合，启动回合末算第一次；期间禁移动和另行动，维持后结束回合；目标/条件失效中断，不退款、不换目标；最终一次战术命中，两原生输入留证，韧性/暴击不重复计算。ElderGuardian 已定周期为每 40 个自身回合末检查，疲劳持续目标 200 回合；支持范围以实际适配为准。

长期能力先通过受权限保护的管理命令授予/撤销已注册且可学习能力，不据此新增 RPG 升级、职业或技能树。标准 buff/debuff 沿原版药效映射，Minecraft 保持原生写入所有权；效果的 grant、来源失效、栈、资源贡献和反应只实现被实际能力使用的部分。

## 7. UI、表现与安全恢复

只使用战术镜头：WASD 平移、QE 旋转；保留热栏与额外能力行。点击目标应能选择能力并自动接近合法位置执行；实体高亮、虚线路径、灰/红预算段和已支持投射轨迹与服务端计划一致，预览不是命中保证。超预算纯移动只提交预算内预览末端，实际可因地形/速度变化提前中断。

UI 绘制与点击使用同一布局变换；菜单/聊天/失焦优先消费输入。相机不改玩家身体，不强加载区块。地形/遮挡问题需真实场景检查；局部透明/剖切是可评估路线，不直接删除遮挡面造成整片世界透视，也不把新渲染系统强塞成首个功能阶段前置。

角色动画、粒子和表现不推进真实实体/物品/药效 tick。保留空战斗日志 GUI，不恢复游戏内文本日志；必要开发诊断必须有界、可关闭且不改变规则。临时 field 可视化从正常产品链移除或显式隔离，不永久保留独立重复协议。

在用户修改有效文档明确 MOD 已发布之前，不维护本模组任何版本间兼容：旧存档/配置迁移、旧网络协议、旧 API 别名及为旧调用补值的兼容分支一律删除，不新增兼容层或版本矩阵。当前格式活动保存/恢复继续维护；不兼容或损坏数据保留原文并拒绝，不自动迁移、修复或重放。服务器世代、能力语义版本、运行修订和 operation ID 属于当前规则身份，仍须保留。Minecraft/loader 目标和第三方内容适配不属于本模组旧版兼容。不强加载成员；已发生效果不回滚，UNKNOWN 不自动重放/退款。

恢复时，玩家尚未登录或所需区块尚未自然加载只表示等待就绪，不因此生成 UNKNOWN 或结束场次，不设实际时间超时。等待期间不接受行动、不推进 AI、环境有效步或挂机跳过；全部就绪后复验并完成 owner 绑定，再开放控制。旧许可仍撤销，无法确认的世界效果仍不重放。管理员或服务器控制台可用 `/dndturn encounter stop <uuid>` 显式结束等待中的场次；清理失败保持待重试状态，不报告成功。

历史结果/回执的七游戏日规则按跨重启累计实际服务器 tick 计算，暂停仍计时、世界快进不缩短，活跃因果/重试引用可延长保留。执行截止与历史保留期分开，不能恢复早期“所有动作超时统一取消”的方案；当前移动/接近截止、环境步截止与挂机跳过的实现边界见状态页。不新增投射物统一寿命。未知存活箭沿已有持久隔离规则，不能在会话结束后自动自由飞行。

## 8. 暂缓及待产品修订

本轮不新增 PvP、完整自然伤害类型/抗性体系、HIDE、Enderman 定点传送、飞行/专属游泳、载具控制、Boss/大型部件玩法、护盾次数、玩家连击、旧格式迁移、第一人称切换或战斗文本日志。普通水中移动及已明确的 TNT 例外保留；结构扩展点存在不等于这些玩法获准开放。

旧资料中流血/破甲及载具等示例不在本轮新增范围。未明确规则只登记于本节，不重新扩展成验收大清单，也不让代理按历史 checklist 自动开放。
