# DNDTurn 开发约定

本页维护玩法、数据与实现合同以及开发方法；工程底线见 [AGENTS.md](AGENTS.md)，实现和验证边界见 [ROADMAP.md](ROADMAP.md)。合同描述应实现的行为，不自动表示完成。当前 [重构 WIP](docs/DNDTURN_REFACTOR.md) 单独保留，其建议须在实施时明确决定，不据此提前改变玩法。

## 工程与构建

| 工程 | Gradle JVM / 编译 | 职责 |
| --- | --- | --- |
| common | JDK 21 可启动 / Java 17 toolchain | 纯 domain/application 与真正共享资源 |
| targets/neoforge-26.1 | JDK 25 / Java 25 | 当前战术功能主目标 |
| targets/neoforge-1.21.1 | JDK 21 / Java 21 | 维护独立构建边界 |
| targets/forge-1.20.1、fabric-1.20.1 | JDK 21 / Java 17 | 维护独立构建边界 |

版本以 target 的 gradle.properties、build.gradle 和 metadata 为准，不在功能修复中顺带升级。共享 mod 信息在根 gradle.properties；平台 metadata、Mixin、访问变换和版本资源留在 target。同路径资源只有一个归属，不依赖覆盖顺序。公开依赖优先 Maven，本地 libs jar 说明用途及额外依赖，客户端依赖不得污染专服。

根目录运行 common 测试：

```powershell
.\gradlew.bat -p common test
```

在 targets/neoforge-26.1 下使用 JDK 25，并让 Gradle 能发现 JDK 17 toolchain：

```powershell
.\gradlew.bat compileJava
.\gradlew.bat build
.\gradlew.bat runClient
.\gradlew.bat runServer
.\gradlew.bat runClient -Pautojs=true
# 按受影响场景替换 name
.\gradlew.bat runGameTestServer -PgameTestSelection=dndturn:<name>
```

各工程可能共用 common/build，本地构建串行。根构建默认只含 common，allTargets 不代表包含 26.1 的全版本发布。26.1 build/check 编译 GameTest 并运行 verifyUiProjection、verifyDebugDiagnostics、verifyControlPolicies，不自动运行 GameTest 或真实客户端。AutoJS 通过显式开关和 localRuntimeOnly 进入本地运行，默认关闭，不进编译/发布依赖；解析成功不等于脚本实机成功。

发布逻辑复用 gradle/target-conventions/publish.gradle；只在明确发布指令下对对应 target 构建、检查产物并执行 publishMods。每包对应单个 loader/Minecraft 目标，令牌只来自环境变量，不提交凭据、IDE 缓存和 build 输出。

## 战斗、成员与 field

玩家主动创建 Encounter；普通世界 Mob 自然索敌不自动建场。多人建场要求其他玩家确认，发起者视为已同意，名单变化复验；自最初请求起 400 个实际服务器 tick 截止，等待时世界正常运行。禁止 PvP，同场不自动互相敌对。

成员是参战玩家及实际仇恨/合法介入的实体。Mob 索敌只读取提交后的最终目标；取消索敌不入场，重复通知不刷新资格/资源，锁定未参战玩家不绕过同意。同一实体只属一个 Encounter，跨场因果介入走安全合并。非敌对 Mob 不因处于 field 而进入先攻；没有敌人时可保持候选轮转和环境参与者。

field 为参战玩家水平凸包外扩默认 35 格，竖向按锚点上下各扩 16；在玩家移动结束及回合开始重锚。成员可在场外合法移动/行动，不自动退出或获免费动作。重叠按既定规则合并，合并/环境 hold 范围与 field 耦合；采样有加载与容量上限，不强加载、不扩为整 chunk。

场外实体攻击成员时，近战在伤害边界、受支持投射物在命中边界立即转为战术结算，加入并建立双向敌对，被转换的原版伤害不重复施加。攻击者仍按先攻排序，下一次自身回合扣一个动作；命中与否、目标随后离场/死亡不免除欠账。PvP 仍拒绝，不恢复延迟到下一行动窗口才处理首击的方案。

EXIT 免费，但只允许自己空闲回合且无反应窗口。到本场最近存活敌人的水平直线距离须达到建场捕获的 escapeDistance（默认 16），任一方向敌对都算敌人，忽略墙体和高度；无敌人时满足距离条件，未知位置拒绝并可重试。提交重采样，不强加载，不传送、不清仇恨、不授予重入豁免。最后玩家退出结束场次；死亡、掉线、换维度和卸载走各自释放路径。

## 回合与行动

普通单位 d20 先攻并稳定处理平手，每次自己回合获得一个动作、一个反应和基础移动预算。默认预算 30 tick，已接入的角色/Mob 映射按捕获来源使用；移动以实际获准主动移动 tick 扣费，不按格、不以传送代替。可分段和行动后继续移动，被动推开不扣受击者移动。合并/重入不重置资格、首击欠账或已花资源。

每场恰有一个环境参与者，显示先攻 -1，按类型排在所有实体后，不占真实成员、不领动作/反应，不可攻击/调查。只有其有效预算完成才结束对应环境窗口，普通单位结束不赠环境时间。

| 行动 | 合同 |
| --- | --- |
| 攻击 | 合法攻击实际开始扣一次动作；查询、选择、接近不收费，到位复验；未命中/零伤害不退，攻击完成不自动结束回合 |
| 移动 | 按获准主动 tick 扣预算；超预算纯移动提交预览预算内末端，地形/速度变化可提前中断 |
| 空手 | 显式能力，不依赖空槽；基础伤害 1、局部原版推开输入 0.4，共一次动作；未命中不推，不触发无关手持钩子，不保证实际位移 0.4 格 |
| DASH / DODGE / DISENGAGE | 各耗动作；分别增加一份捕获基础移动、到下次自身回合前使攻击者劣势、本回合主动移动不触发借机 |
| HELP | 耗动作，协助者邻接敌人并指定同场盟友；盟友为同场玩家或主人关系确认的驯服生物，无额外距离限制，敌对优先；优势至协助者下次回合前，首次合法攻击登记时消费 |
| 借机攻击 | 主动离开威胁范围前暂停；反应者选武器/确认，共享最多 100 实际服务器 tick，稳定先攻复验、消费反应后按条件续走；被动推开不触发 |
| 物品/放置/破坏 | 按原版接受边界收费；已支持食饮、弓蓄力/弩装填在当前回合自动完成，只耗一次动作，之后仍能继续行动 |
| 方块自身交互 | 不耗普通动作，必要接近耗移动；失败不回退手持 useOn，打开菜单与存取/配方/交易分别授权 |
| 整理/调查 | 合法整理换装沿免费规则；运行计划期间不换槽；调查免费、只读、有界且受公开权限限制 |

近战沿已定一格各轴范围和可见性，可先接近；普通远程保持六格，计划余量不扩大实际射程。特殊投射物保留其原版效果/消耗，合法释放收一次动作，延迟效果仍受过程、加载、保护和范围约束。Skeleton 普通箭免箭/弓耐久由来源消费政策表达，仍耗动作，不由核心按物种特判或扩展为特殊箭支持。

## 数值、角色与内容

基本攻击为 d20 + 来源攻击加值 对 AC，自然 1 失手、20 命中并暴击；优势两取高、劣势两取低，同类不叠加，同时存在抵消。每场每名攻击者一次首攻优势资格：首次合法攻击登记前目标尚未锁定攻击者时获得；非法请求不消耗，未命中不返还。

普通原生映射保留 `AC = max(0, floor(armor)) + 持盾2`，基础伤害经 `floor(max(0, 输入 - max(0, floor(toughness))) × 暴击倍率)` 计算，暴击倍率为 2。已创建玩家角色使用职业/六维、明确装备映射的玩家规则；不要把旧原生公式写成所有玩家的唯一公式。当前混装/不完整套装在角色 AC 路径按无甲处理；未创建角色和非玩家继续原生 AC。已映射 Mob 的命中/伤害来自物种档案，玩家武器来自选择证据，均不重复加算原生装备贡献。数值迁移不暗改玩法。

玩家角色基础包含 27 点购点、种族/职业选择、XP/等级/熟练、ASI/子职选择与装备。数据保存在 Actor 长期状态；当前生命及最大生命仍由原生实体拥有，成长只通过受控路径更新最大生命。完整职业特性、法术和成长内容的接入状态见 ROADMAP，不因存在定义或 UI 就宣布可玩。

怪物设计仅取用户提供资料及其规范化数据 [vanilla-mobs.yaml](docs/data/vanilla-mobs.yaml)，不自行引用外部图鉴补玩法。该表的 design 字段是设计输入、status 是历史标签，不是运行验收表。怪物 HP/AC 沿原生 1:1（盾另 +2），设计 ac/hp_avg/hp_dice 不覆盖运行时；速度中的尺直接按 tick 预算解释。无数据第三方 Mob 的默认模板为六维 10、原生 HP/AC、30 tick 地面移动、+5 命中和 10 钝击近战。

内容从内置 dndturn-content/defaults.json、default-mobs.json 及世界目录 classes/races/mobs JSON 加载；无效文件拒绝，不悄悄修补。Encounter 固定内容快照，后加入者复用，reload 只生成新快照；合并保留各参与者原目录，新增参与者采用主场目录，保存恢复保留原语义。装备按完整注册 ID 映射，不按 namespace 被剥离后的同名物品猜属性。

豁免由服务端 d20 + 属性/明确豁免加值对 DC，玩家熟练来自职业，Mob 显式 saveBonuses 优先，否则取六维修正；自然 1/20 不自动成败。SaveRollEvent 在掷骰后提交前允许调整 die/bonus/DC，玩家动作栏显示结果，无 QTE、自动重掷或重试。多段伤害、抗性、免疫、条件和特殊能力必须贯穿实际执行及逐项结果，类型定义存在不表示已接通。

## Actor 读取与能力扩展

| 数据 | 写入权威与读取方式 |
| --- | --- |
| 位置、身体、生命、吸收、装备、库存、耐久、原生属性/药效 | Minecraft/原生实现；核验当前实例后有界观测 |
| 角色选择、学习/准备、Actor 自有资源 | Actor 长期状态 owner；不可变快照 |
| 战术条件效果 | Actor 效果 owner；实例快照 |
| 成员、先攻、敌对、动作/反应/移动余额 | Encounter；组合成员视图 |
| 行动、引导、投射与世界过程 | 既有运行 owner；只读过程引用/检查点 |
| 当前控制权 | 平台控制绑定和许可链；描述不构成许可 |

统一读取不统一写入：复用 ActorSnapshot、ActorPersistentState、ActorRuntimeState、CombatantSnapshot 与 CharacterSheet，不建立可写 ActorInstance 第二 owner。ActorId 与 InstanceId 分开，UUID 相同不复用旧许可。定义只提供所属默认事实，规则分类/体型不覆盖原生类型/尺寸；ResourceDescriptor 不凭声明创造余额或刷新。

属性链为原生 base + 活跃 modifiers → 原生 effective → 规则映射 → Actor 效果/持续能力贡献 → 最终战术值。分别保留原生与战术键、单位及采样证据。装备已计入 effective 时解释不再次相加；角色攻击属性与本次武器/能力输入分开。解释保留阶段、运算、贡献来源与完整性，未知来源不猜测，截断不改变有效值，重建不一致时标记不完整，不虚构差额。

查询声明依赖，核验实例后同步捕获并派生，同一链用于发现、调查和执行复验。缓存仅限一次同步读取，绑定 Actor 修订；capture ID 证明同次采样，tick 不等于原生修订。解释按需捕获，不让常规发现遍历库存；本人完整资料可读至多 64 槽摘要，不编码全部组件或强加载。未授权属性/来源只向本人公开，每次翻页重新采样，不承诺跨请求同刻快照。

装备证据包含槽位、数量/组件指纹、Actor/实例及已审计写入代次；同值替换也失效。原生消耗可更新当前操作的继续证据，不生成新许可。指纹不是物品 UUID；不承诺识别第三方绕过入口又恢复同值的写入。原生 modifier 活跃与能否证明装备来源分开，关联核对属性、ID、运算、数值和实际槽位，不按名称猜因果。

扩展在构造/common setup 注册并统一冻结；定义、来源、事实、AI、执行器、观察、表现各负其责，缺少专用解释器不关闭通用入口。AI 使用有界感知/记忆和能力语义选择后续行为，敌对关系不等于可见性。

Learning 明确 UNAVAILABLE、IMMEDIATE、PREPARED；内置操作、装备及物种能力不自动可学。可学习原生能力须有长期来源适配，准备要求来自冻结定义。管理员/控制台通过 `/dndturn actor ability list|grant|revoke|prepare|unprepare` 管理单个已加载玩家/Mob；grant 参数为 target、ability、semanticVersion，撤销/准备使用 target、grantId。不离线写入或强加载。同能力/语义重复授予返回已有 grant，撤销再授予获得新身份；取消准备/来源失效拒绝旧计划，不复活旧证据，不撤销已发生效果和费用。

## 过程、环境与恢复

沿已有 Process 值、运行 owner、有限阶段驱动、检查点和触发 outbox 扩展。Actor-owned 与 Environment-owned 共享执行概念，时钟和归属明确；恢复已知阶段不重做不可逆 start、不重掷已记录随机。

同步交互/邻居响应按原版；计划延迟、周期、生产、危险过程按指定有效步骤推进。红石可同步点燃 TNT，中继延迟与 TNT 引信分别计量；80 步引信在每窗口 30 个有效步时于第三窗口结束。全局昼夜/天气继续原版，区域生成/降雪/结冰/雷击另行声明托管范围，不用环境钟替换世界钟。

参战持续药效（含第三方命名空间）按自身回合末及捕获 roundTicks 换算，着火等按已接过程边界结算。未知特殊回调暂停并显示需适配，基础属性/展示/期限仍接入。瞬时治疗/伤害/饱和不另掷攻击，保留原版强度、距离衰减、亡灵反转、免疫/取消/吸收，经当前操作有限许可结算一次；持续瞬时实例按周期处理。即时显示回执在本轮环境回合实际结束清除，自身回合末不清，离场释放、不持久化、不重放。效果 UI 只读服务端期限。

原版 buff 接入不擅加抗性减伤、隐身优势或急迫动作。饥饿按有效回合时长累计；不祥之兆自身回合末检查转换，袭击之兆最后有效期限边界尝试创建，试炼之兆保留外部消费者。虫蚀/渗浆/盘丝/蓄风由真实受伤/死亡触发，受 field、加载、保护、数量和逐项观察限制；退出/恢复不代替死亡。

Creeper 每次合法 Charge 耗动作加一层，三层在自身回合末爆炸；退出按比例映射原生引信并保留点燃状态。Guardian 合法启动耗动作，默认三回合引导，启动回合末算第一次；期间禁移动/另行动，目标失效中断、不退款换目标，最终一次命中、双原生输入留证且不重复减伤/暴击。ElderGuardian 每 40 个自身回合末检查，疲劳持续目标 200 回合。这些合同的完成范围见 ROADMAP。

队列接管保留剩余 delay、优先级、相对顺序、查询/去重及唯一 owner；入域/离域/合并/卸载不补演等待、不重置相位。恢复待玩家登录/区块自然加载，不设实际时间超时、不因此标 UNKNOWN 或结束；等待时拒绝行动，暂停 AI/环境/挂机跳过，全部就绪复验绑定后开放。管理员可 `/dndturn encounter stop <uuid>` 结束等待，释放失败保持可重试。旧许可撤销，未知效果不重放，未知存活箭保持持久隔离，不在停场后自由飞行。

历史/回执七游戏日保留按跨重启累计实际服务器 tick 计量，暂停仍计时、快进不缩短；活跃因果/重试引用延长保留。执行截止与保留期分开，不恢复所有动作统一超时取消或给投射物添加统一寿命。

## 客户端与表现

保留战术镜头、热栏和能力行，WASD 平移、QE 旋转；默认空格在 250ms 内松开请求结束回合，长按升高视角，独立 Enter 绑定保留。以单调实时时钟识别手势，菜单、失焦、同意窗口、身份变化和退出取消手势。

目标选择→发现/预览→接近→复验→执行→继续移动/结束均使用既有客户端会话和后端。高亮、路径、预算颜色和已支持轨迹与服务端计划一致；绘制/命中共用布局变换，原版 Screen/聊天/失焦优先。镜头不移动玩家，不强加载；剖切/遮挡需真实场景检查，不直接删除大面积世界表面。

表现不推进原生 tick；保留空日志面板。临时诊断有界、可关闭，关联 operation/阶段/身份/费用/结果，日志失败不改结果，不提交敏感数据或常驻探针。

## 验证与维护

优先复用现有断言保护：分层依赖；唯一成员/资源/终态；同 ID 幂等与异负载拒绝；接受边界收费；有效时间与队列迁移；实例/来源/随机/释放；查询只读、有界输入、非有限值拒绝和迟到投影失效。测试名字、数量、行数及阶段不是保留或新增依据。

| 改动 | 必要证据 |
| --- | --- |
| 文档 | 本地链接、合同一致性、受保护文件不变；不启动游戏 |
| 构建/依赖 | 配置解析、受影响构建及产物/发布依赖隔离 |
